# Legacy prototype

`trilha-criativa-legacy.html` is the navigation prototype built before the product moved to a catalog of creative paths. It is kept verbatim as a reference for visual language and interaction patterns.

It is **not** the current product:

1. All data is simulated. There is no real AI, Notion, database or authentication. The only complete job is the fictional "Brisa" demonstration.
2. It still contains the **Matter** ("Matéria prima") and **Combinations** ("Combinações") stages, which are no longer part of the product flow.
3. What it calls "caminhos criativos" are generated directions, which are now called **concepts**.

See `docs/adr/0001-catalog-creative-paths.md` for the current flow and terminology.

To view it, open the file in a browser. It loads React and Babel from public CDNs, so it needs network access to `cdnjs.cloudflare.com` and `unpkg.com`.
